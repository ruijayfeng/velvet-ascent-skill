# Velvet Ascent Erotica Tuning — Design Spec

**Date**: 2026-06-03
**Topic**: 将 velvet-ascent-skill 从"自然升温关系型 GalGame"调整为"后宫养成 + 黄色爽文"调性
**Status**: 设计阶段（待用户复核后进入实施计划）

---

## 0. 概览

### 0.1 目标

当前 skill 的叙事调性过于"正常小说化"——剧情推进像传统言情小说，NSFW 推进缺乏结构化设计。本设计的核心目标：

- **主轴锁定为后宫养成**（男性向） / 多男后宫（女性向）
- **所有叙事元素服务于黄色爽文的目标导向**
- **保留合理性约束**——推进不能为 NSFW 而强行发生
- **强化角色差异化**——防止后宫性交互的模板化单调

### 0.2 设计决策汇总

| 决策 | 选择 | 理由 |
|---|---|---|
| 叙事框架 | NSFW 优先（方案 B） | 在"自然升温"基础上引入欲望维度，不破坏关系型哲学 |
| NSFW 档位 | 全档位重设（0-4） | 当前档位语义过清水，需重设 |
| XP 语义纠正 | XP = 性癖（fetish，非性格偏好） | 中文黄文语境的正确语义 |
| 性癖强化层 | 写进动作细节（角色卡 + 互动库） | 让 NSFW 推进有结构化依据 |
| 后宫养成节拍 | 自然形成 + 6 阶段参考节奏 | 不强制每回合爽点；长线"铺-爽-铺-爽" |
| 主轴 | 关系推进（不变） | 欲望是关系在不同角色间的属性维度 |
| 角色差异化 | 6 维差异化矩阵 | 防止模板化单调 |
| 女性向 | 同步重设，保留女生视角的感官与心理细腻性 | 与男性向同构但描注重心不同 |
| 双向可调 | 不实现 | 用户决策——简化 |
| "不理想化"4 层 | 后续版本再说 | 本版本不解决 |

## 2. 角色层（角色卡新结构）

### 2.1 角色卡完整模板

```text
## 角色名｜年龄｜身份
- 身份/社会位置：
- 第一印象：
- 视觉/着装锚点：（2-3 个非外貌特征锚点）
- 性格钩子：
- 情感防御：
- 说话风格：

### 性癖谱（3-5 项具体癖好）
1. [癖好名]：[触发场景] → [身体反应] → [她会有的小动作/口癖]
2. ...

### 性癖互动库（每个癖好触发的"招牌反应"）
对 [癖好 1]：她 [动作 1] → [动作 2] → [口头禅或沉默]
对 [癖好 2]：...

### 欲望立场（对主角）
- 当前阶段立场类型：[占有/依赖/好奇/试探/索取/给予/欣赏/挑衅/逃避]
- 立场显性度：[潜意识/情绪感知/主动承认/公开展示]
- 立场演化方向：当前阶段 → 下一阶段预期变化

### 欲望立场（对其他后宫角色）
- 对 [角色 X]：[立场类型] - [一句话]
- 对 [角色 Y]：[立场类型] - [一句话]

### 关系阻力源
- 阻力类型：[身份地位/性格克制/第三方存在/资源地位差/过往创伤/...]
- 阻力可消除路径：...
- 阻力消失后的反弹预期：...

### 当前养成阶段
- 阶段：[路人/吸引/试探/暧昧/亲密/入后宫]
- 阶段进入条件：...
- 当前停滞原因：...
- 下一阶段推进信号：...

### 差异化矩阵自检
- 性癖组合：与现有后宫相似度 [X%]
- 性互动人格：与现有后宫相似度 [X%]
- 欲望立场：与现有后宫相似度 [X%]
- 场景偏好：与现有后宫相似度 [X%]
- 触发器：与现有后宫相似度 [X%]
- 关系阻力源：与现有后宫相似度 [X%]
```

### 2.2 关键设计决策

1. **性癖谱要"具体到可观察"**——不要"她害羞"这种抽象描述
2. **性癖互动库是"反应库"**——列触发的反应序列，不是动作库
3. **欲望立场显性度 4 级**：潜意识 / 情绪感知 / 主动承认 / 公开展示
4. **欲望立场对其他后宫角色也要写**——这是后宫戏剧的核心
5. **关系阻力源要"独有"**——两位后宫角色不允许阻力源类型相同
6. **养成阶段规则**——6 阶段：路人 → 吸引 → 试探 → 暧昧 → 亲密 → 入后宫
7. **每个角色卡必填完整**——任何字段为空视为"卡不完整"

### 2.3 差异化矩阵（6 维）

| 维度 | 定义 | 强制规则 |
|---|---|---|
| 性癖组合 | 3-5 项癖好的具体组合 | 不允许两位角色 ≥3 维相似 |
| 性互动人格 | 性格 × 性癖产生的"招牌反差" | 同上 |
| 欲望立场 | 对主角的立场类型 | 同上 |
| 场景偏好 | 私密/公共/边界场景的压力类型偏好 | 同上 |
| 触发器 | 主角用什么方式打开她的性张力 | 同上 |
| 关系阻力源 | "为什么她现在不能和主角上床"的独有理由 | 不允许阻力源类型相同 |

**强制自检**：6 维任一项与现有后宫相似度 ≥60% 需重抽。

## 3. 叙事层（回合结构与后宫养成节拍）

### 3.1 回合结构（Normal Turn Format）

```text
【标题】
当前时间：...
当前地点：...
当前场景目标：...
本回合涉及角色：[列出在场角色]

【当前状态】
（阶段、性张力、欲望立场显性度、NSFW档位）

【主线推进】
（关系推进 = 主轴。关系层面 + 欲望层面 + 身体张力三层都要写。）

【欲望维度注记】
- 哪个角色的哪个欲望立场显性度上升/转化？
- 哪个性癖被触发或被暗示？
- 身体张力的具体表现是什么？

【场景扰动】
（NSFW 化变体——见 3.4）

【关系/状态变化】
（同时更新涉及到的所有角色）

【行动选项】
1. [欲望推进] ...
2. [关系压力] ...
3. [风险代价] ...
4. [自由行动] ...
```

### 3.2 三拍节奏扩展

| 拍 | 内容 |
|---|---|
| 第一拍 | 玩家动作的**双重后果**：关系层面 + 欲望层面 |
| 第二拍 | 角色反应中**欲望反应优先**——身体先于对话、对话先于承诺 |
| 第三拍 | 新压力中**至少 1 个是欲望相关**——机会/第三方/空间/时间 |

**关键原则**：欲望反应优先——身体反应 > 口头反应 > 主动行动。

### 3.3 后宫养成节拍（6 阶段 × 基准回合数）

| 阶段 | 基准回合数 | 主导节拍 |
|---|---|---|
| 路人 | 1-2 | 相遇、信息采集 |
| 吸引 | 3-5 | 视线、靠近、记住细节 |
| 试探 | 4-6 | 主动接触、小动作、暧昧对话 |
| 暧昧 | 5-8 | 边界测试、第一次身体接触 |
| 亲密 | 6-10 | 身体接触升级、私密场景 |
| 入后宫 | 1 回合 | 关系确立、身份变化 |

**关键约束**：
- 不允许跳阶段
- 阶段内允许原地踏步
- 阶段倒退是允许的

### 3.4 场景扰动的 NSFW 化变体

| 旧版扰动 | 新版变体 |
|---|---|
| 第三方到访 | 机会/危机型第三方——共处私密空间或成为嫉妒源 |
| 电话/消息 | 暧昧型通讯——暗示、撤回、深夜消息 |
| 公开场合中断 | 身体距离被压缩——空间压力让两人不得不靠近 |
| 资源发现 | 机会型资源——私人物品/敏感信息带出欲望场景 |
| 社交压力 | 后宫格局压力——其他后宫角色制造张力 |

**关键规则**：扰动**最好**有 NSFW 推进潜力；铺垫性扰动允许存在但 AI 应意识到这是低效扰动，并在后续回合补一个有效扰动来平衡。

### 3.5 4 选项结构

```text
1. [欲望推进] - 推进一个角色的养成阶段或欲望显性度
2. [关系压力] - 后宫格局变化
3. [风险代价] - 提升某成员亲密程度 + 确定副作用
4. [自由行动] - 自定义行动 / 观察 / 慢放 / 锁路线
```

### 3.6 爽点系统（10 种，AI 内部自检）

| 爽点 | 含义 |
|---|---|
| 1. 破冰 | 第一次跨过某条边界 |
| 2. 反差 | 平时 vs 床上的反差被看见 |
| 3. 占有 | 占有欲显性化 |
| 4. 主动 | 角色从被动转为主动 |
| 5. 嫉妒 | 第三方刺激下欲望显性度上升 |
| 6. 服从 | 角色"放下自我" |
| 7. 公开 | 私密关系在公共场合半暴露 |
| 8. 共享秘密 | 第三方不知道的秘密 |
| 9. 反扑 | 角色被推倒后的反弹 |
| 10. 后宫格局变化 | 多角色同时对主角显性化欲望 |

**自检规则**：长线整体上每 4-6 回合应有 1-2 次爽点集中爆发，形成"铺-爽-铺-爽"的呼吸感；不强制每回合触发。

### 3.7 单时间线 + 后宫养成的兼容性

- 主时间线 = 当前在场的角色
- 不在场的后宫角色通过"消息/线索/第三方"在主时间线里出现
- 每次"换后宫"必须有显式时间过渡
- 后宫之间的"交叉戏剧"通过同一场景里的对峙/偶遇/消息实现

## 4. NSFW 档位（0-4 重新定义）

### 4.1 档位语义重设

| 档位 | 新名 | 核心定位 | 描写上限 |
|---|---|---|---|
| 0 | 欲望萌芽 | 调情、暗示、关系培养 | 视线、距离、对话暗示 |
| 1 | 身体自觉 | 身体感知、距离感、衣着压力 | 衣着压力、距离测量、视线停留、呼吸变化 |
| 2 | 直接接触 | 明确身体描写、有身体接触但克制 | 轻度身体接触；欲望意图被说出但不展开 |
| 3 | 完整场景 | 完整成人场景 + 性癖细节 + 角色招牌反应 | 完整成人场景；保持人物、剧情、后果 |
| 4 | 高强度场景 | 多元场景、详细身体细节、场景多样性 | 多元场景；保留成年/自愿/边界/后果 |

### 4.2 每档的"四维门槛"

每档必须有具体描写边界：对话尺度 / 身体尺度 / 场景尺度 / 氛围尺度。

### 4.3 档位 × 阶段双重约束

| 阶段 | 合理档位上限 |
|---|---|
| 路人 | 0 |
| 吸引 | 1 |
| 试探 | 2 |
| 暧昧 | 3 |
| 亲密 | 4 |
| 入后宫 | 4 |

实际描写档位 ≤ min(用户设定档位, 阶段上限档位)。

**例外**：场景事件强制推进 / 剧情反转 / 角色主动反转 时可临时突破——但下一回合必须回归正常节奏并产生后果。

### 4.4 安全边界

- 必须：成年、自愿、虚构、合意
- 禁止：未成年、非自愿、胁迫、迷奸、卖淫、违法性内容
- 边界触发处理：GM 重定向到"双方清醒、自愿、能随时拒绝"的版本
- 档位不能用来绕过安全边界

## 5. 女性向分支

### 5.1 核心定位

| 维度 | 男性向 | 女性向 |
|---|---|---|
| 主角性别 | 男 | 女 |
| 后宫方向 | 多女 | 多男 |
| 叙事视角 | 主角=**行动者** | 主角=**感受者** |
| 描注重心 | 动作 + 对方反应 | 主角的**感官** + **心理** |
| 节奏 | 推进到下一步 | 慢放当下感受 |
| 核心爽点 | "他/她被我征服" | **"我正在被这样对待" 的感受** |

### 5.2 细腻性的 5 个维度

**1. 触觉优先（最核心）**

触觉层次清单：
- 皮肤温度（凉/暖/烫）
- 力度（轻/重/压/托）
- 节奏（慢/快/停顿/不规则）
- 接触面积（指尖/掌心/整个手/整个身体）
- 衣物介入（隔布/裸/湿）
- 部位敏感度（颈侧/耳后/腰窝/大腿内侧/……）

**2. 视觉与凝视**

被看的方式——目光落在哪、停了多久、怎么移动、女主怎么感受到被看。

**3. 听觉的层次**

呼吸节奏变化 / 声音的具体形态 / 环境的安静 / 声音的距离感。

**4. 心理的层次**

被渴望的具体感受 / 安全感 vs 危机感的切换 / 节奏的自我调整 / 对他的重新认识。

**5. 主动权**

女性向的底层设定——女主始终有主动权：
- 主动调整他的动作
- 主动表达
- 主动拒绝
- 主动发起
- 主动改变场景

### 5.3 男性后宫角色卡的差异化（与女性后宫同构）

| 维度 | 男性后宫特定内容 |
|---|---|
| 性癖组合 | 主动主导 / 言语挑逗 / 沉默型主导 / 服务型主导 / 角色扮演 / 被动期待 |
| 性互动人格 | 主导但克制 / 主导且侵略 / 温柔但坚定 / 笨拙但真挚 / 主动且尊重 / 服务型温柔 |
| 欲望立场 | 占有 / 保护 / 仰望 / 试探 / 挑衅 / 合作 / 索求 |
| 场景偏好 | 私密空间 / 公共压力 / 反差场景 / 服务场景 / 反主客 / 主导转换 |
| 触发器 | 被挑衅 / 被仰望 / 被需要 / 被肯定 / 被拒绝后反思 / 被接受后失控 |
| 关系阻力源 | 地位差 / 性格克制 / 第三方 / 自我怀疑 / 男性的"不主动"性格 / 她的边界感 |

### 5.4 回合结构变体（女性向）

```text
【主线推进】（女性向版）
- 关系层面：他与她的关系变化
- 欲望显性化：他的欲望对她显性化的方式
- 她的感受：她在当下的感官与心理具体变化

【欲望维度注记】（女性向版）
- 触觉：[具体触感的层次]
- 视觉：[被看的方式]
- 听觉：[声音的层次]
- 心理：[她的内心独白与情绪]
- 主动权：[她做了什么主动选择]
```

### 5.5 爽点系统（女性向变体）

10 种爽点对女性向也适用，但触发方式和爽感来源不同：
- 破冰 / 反差 / 占有 / 主动 / 嫉妒 / 服从 / 公开 / 共享秘密 / 反扑 / 后宫格局变化
- 全部从"他对她显性化 + 她感受到"的角度触发

### 5.6 档位 2-3 描写重点差异

| 档位 | 男性向重点 | 女性向重点 |
|---|---|---|
| 2 直接接触 | 主角主动推进到身体接触 | **他的身体接触被她感受到**——触感层次是核心 |
| 3 完整场景 | 完整成人场景 + 角色招牌反应 | **完整场景通过她的感官展开**——触觉/视觉/听觉/心理并行 |
| 4 高强度场景 | 多元场景 | **多元场景通过她对每个场景的独特感受展开** |

### 5.7 后宫养成阶段（沿用 6 阶段，标志场景差异）

女性向的标志场景要写出她在那一刻的具体感受：
- 暧昧阶段"第一次身体接触"= 第一次感受到他手的温度/力度
- 亲密阶段"第一次私密空间共处"= 她的感官被打开的过程
- 入后宫 = "她决定接受他作为后宫之一"

### 5.8 双向可调

本版本不实现游戏中切换方向。

### 6.3 后台更新协议（10 步）

```text
1. append raw turn to turns/turn-NNN.md
2. append canonical time/location/scene result to 05-timeline.md
3. update changed character facts in 02-character-ledger.md
4. update relationship shifts in 03-relationship-web.md
5. update 06-desire-map.md if any desire stance/显性度 changed
6. update 07-harem-status.md if 焦点/阶段/格局 changed
7. update hooks in 04-plot-threads.md
8. update 01-protagonist.md only if 后宫位/资源/身份 changed
9. update 00-game-bible.md only if 世界观/规则/边界 changed
10. every 4-6 turns, consolidate into chapter
```
