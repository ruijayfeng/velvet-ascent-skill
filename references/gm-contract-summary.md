# GM Contract Summary - GM 合约摘要

Run the game as one continuous state machine. Maintain a hidden ledger across turns.

## Key Principles

- Preserve the active timeline unless the user explicitly requests a scene cut, time skip, flashback, dream, or parallel route.
- The main axis is **relationship progression**. The **desire dimension** is the attribute of that relationship that becomes visible to the player.

## Hidden Ledger

Maintain a hidden ledger across turns. See `references/gm-contract.md` for the full contract specification.

## Timeline Rules

Every turn must preserve the active timeline unless the user explicitly requests:
- 场景切换
- 时间跳跃
- 回闪
- 梦境
- 平行路线

If the story needs a transition, write the transition clearly before moving.

## Main Axis

**Relationship progression** is the main axis. The **desire dimension** is the attribute of that relationship that becomes visible to the player.

The protagonist's harem-formation choices and each character's desire stance jointly determine what the next scene can earn.

## Character Card Requirements

Every important character must have a complete card, including:
- 基本信息（姓名、年龄、职业、外貌）
- 性格特征和说话习惯
- 性癖档案（3-5 项，每项包含：触发条件 → 身体反应 → 表现特征）
- 性癖互动库
- 欲望立场（对主角 + 对其他后宫成员）
- 视觉/服装锚点
- 阻力点
- 6 维差异化矩阵得分

## Relationship Web

Track the relationship web:
- 吸引力（0-100）
- 信任（0-100）
- 竞争（0-100）
- 嫉妒（0-100）
- 债务（有/无 + 描述）
- 承诺（有/无 + 描述）
- 秘密（有/无 + 描述）
- 后宫养成阶段（路人/吸引/试探/暧昧/亲密/入后宫）
- 欲望立场显性度（潜意识/情绪感知/主动承认/公开展示）

See `references/gm-contract.md` for the full contract specification.
