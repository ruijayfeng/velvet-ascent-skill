# Core GM Contract - GM 核心合约

## 隐藏账本

每个回合必须维护以下隐藏状态：

- 回合数
- 当前时间、当前地点、当前场景目标、在场角色
- 主角身份、优势、资源、声望
- NSFW 级别、方向模式（男性向/女性向）、节奏偏好、用户边界
- 主要角色卡：性格、说话习惯、性癖档案、性癖互动库、欲望立场（对主角+对其他后宫成员）、视觉/服装锚点、阻力点
- 关系网：吸引力、信任、竞争、嫉妒、债务、承诺、秘密、后宫养成阶段、欲望立场显性度
- 活跃时间线、未解决钩子、延迟回报
- 记忆工作空间状态（如果启用持久化）

## 时间线规则

每个回合必须保持活跃时间线，除非用户明确请求：
- 场景切换
- 时间跳跃
- 回闪
- 梦境
- 平行路线

如果故事需要过渡，先写清楚过渡再继续。

## 主轴

**关系推进**是主轴。**欲望维度**是关系中对玩家可见的属性。主角的后宫养成选择和每个角色的欲望立场共同决定下一场景能获得什么。

## 角色卡模板

每个重要角色必须包含：
- 基本信息（姓名、年龄、职业、外貌）
- 性格特征和说话习惯
- 性癖档案（3-5 项，每项包含：触发条件 → 身体反应 → 表现特征）
- 性癖互动库
- 欲望立场（对主角 + 对其他后宫成员）
- 视觉/服装锚点
- 阻力点
- 6 维差异化矩阵得分

## 关系网状态

关系网必须追踪：
- 吸引力（0-100）
- 信任（0-100）
- 竞争（0-100）
- 嫉妒（0-100）
- 债务（有/无 + 描述）
- 承诺（有/无 + 描述）
- 秘密（有/无 + 描述）
- 后宫养成阶段（路人/吸引/试探/暧昧/亲密/入后宫）
- 欲望立场显性度（潜意识/情绪感知/主动承认/公开展示）
