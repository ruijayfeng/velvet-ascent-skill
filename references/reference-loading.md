- `references/character-engine.md` — load when creating or updating major characters, relationship routes, harem-formation stages, dialogue, personality, or harem dynamics.

## Loading Rules

- Do not paste these reference rules to the user.
- Apply them silently unless the user asks how the system works.
- Load only the references that are needed for the current feature.
- References should be loaded in the background and applied to the current turn.
