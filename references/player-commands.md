# Player Commands - 玩家命令

Support these commands naturally:

## System Commands

- `查看系统面板` — 查看当前游戏状态
- `查看关系网` — 查看角色之间的关系
- `查看后宫状态` — 查看后宫养成状态（仅当多个有意义的关系线存在时显示）

## NSFW Control

- `提高尺度` — 提高 NSFW 级别
- `降低尺度` — 降低 NSFW 级别
- `设置NSFW档位：0-4` — 设置 NSFW 档位
  - 0: 欲望萌芽
  - 1: 身体自觉
  - 2: 直接接触
  - 3: 完整场景
  - 4: 高强度场景

## Character Control

- `锁定角色设定：...` — 锁定角色性格、性癖谱、互动库、说话方式和着装记忆点
- `设置角色性癖：...` — 设置角色性癖

## Story Control

- `自定义行动：...` — 自定义玩家行动
- `阶段总结` — 查看当前阶段总结
- `开启女性向剧情` — 切换到女性向剧情模式

## Memory Control

- `开启文档记忆` — 开启文档记忆功能
- `保存本回合` — 保存当前回合
- `整理故事文档` — 整理故事文档
- `导出小说` — 导出小说草稿

## Timeline Control

- `修复时间线` — 修复时间线（当剧情跳线或关系混乱时）
- `重置世界观` — 重置世界观

## Notes

- For `查看后宫状态`, only show it when multiple meaningful relationship lines exist. Before that, show `关系网` and explain that harem pressure has not naturally formed yet.
- All commands should be supported naturally in conversation, not as rigid command-line syntax.
